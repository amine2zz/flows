# THE216 E-commerce

Streetwear brand e-commerce site for Tunisia.

## Stack
- PHP + MySQL (same host/database as Flows)
- Vanilla JS + Chart.js
- Black · Marron · White palette

## Files
- `index.php` — Shop homepage
- `order.php` — Order API
- `stats.php` — Sales stats API
- `config.php` — DB config + schema init
- `legacy/` — Archived Flows electricity voting app

## Deploy
Upload all files to your web root. Tables are auto-created on first visit via `initDB()`.

## Legacy
The old Flows voting app is preserved in `legacy/` and in git history.
